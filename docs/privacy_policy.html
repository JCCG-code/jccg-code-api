Privacy Policy for Stories Factory

Last Updated: [Date you upload this file]

This Privacy Policy describes how Stories Factory ("we", "us", or "our") collects, uses, and shares information in connection with your use of our automated content generation and publishing service.

1. Contact Information

If you have any questions about this Privacy Policy, you can contact us at: jccuadradogracia@gmail.com

2. Information We Process

Our service is an automated workflow designed to generate and publish content. To operate, we process the following types of information:

  • Social Media Credentials: We securely store access and refresh tokens for TikTok and YouTube APIs to authorize content uploads on your behalf. These are managed through the encrypted credential system of a locally-run n8n instance.
  • AI-Generated Content & Data:
    • Seeds: Story ideas ("seeds") generated by AI are stored in a MongoDB database collection named storyseeds.
    • Generated Media: Audio, voice, music, images, and final video files are created using Google Cloud AI services (including Gemini, Imagen, Veo, and Lyria models) and are temporarily stored in a Google Cloud Storage bucket.
    • Job Data: Information about a generation job, including links to the media stored in Google Cloud Storage, is saved in a MongoDB database collection named jobs.
  • API Response Data: We process responses from social media APIs after a successful upload, such as the video ID and public URL.

3. Purpose of Data Processing

The sole purpose of processing this data is to automate the creation of AI-generated video content and publish it to the user's connected social media accounts (TikTok and YouTube) at the user's request.

4. Data Sharing with Third Parties

To provide our service, we share data with the following third-party services:

  • Google Cloud: We use Google Cloud's AI models for content generation and Google Cloud Storage for temporary storage of media files.
  • MongoDB: We use a MongoDB database to manage the state of content generation jobs.
  • TikTok: We share the final video file and its metadata (title, description) with the TikTok API to publish the content.
  • YouTube: We share the final video file and its metadata with the YouTube API to publish the content as a "Short".

The entire process is orchestrated by a self-hosted n8n instance running locally on the user's computer, ensuring no other third party has access to the workflow data.

5. Data Security

We take the security of your information seriously.

  • The entire workflow runs locally on the user's machine within a Docker environment.
  • Sensitive credentials for TikTok and YouTube are encrypted and securely stored using the built-in credential management system of n8n.
  • Access to Google Cloud, MongoDB, and other services is managed via API keys and credentials also stored securely within n8n.

6. Data Retention and User Rights

We are committed to processing data only for as long as necessary.

  • Data Retention: Our system is designed to be lightweight and stateless. Data in Google Cloud Storage and MongoDB is temporary and is overwritten or deleted after the content has been successfully published to the target social media platforms. The only persistent copy of the content remains on the final social media platform (TikTok/YouTube).
  • User Rights: As the sole user of this local service, you have complete control. You can access, modify, or delete your credentials and workflow data at any time within your local n8n and Docker environment.

7. Changes to This Policy

We may update this Privacy Policy from time to time. We will notify you of any changes by posting the new Privacy Policy on this page.
